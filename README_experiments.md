# Вычислительные эксперименты метода Ричардсона

## Запуск

Сборка через CMake:

```bash
cmake -S . -B build
cmake --build build
./build/Richardson_iteration
```

Программа создаёт в текущем рабочем каталоге три CSV-файла:

- `experiment_eps.csv` — `eps = 10^-1, ..., 10^-16`;
- `experiment_det.csv` — `det(D) = 10^0, ..., 10^-16`;
- `experiment_order.csv` — все шесть перестановок трёх параметров.

## Контролируемые данные

- размерность: `N = 10`;
- seed генератора: `1`;
- `Q` и `x_star` создаются один раз и повторно используются во всех опытах;
- `D` первоначально создаётся положительной диагональной матрицей с заданным определителем `1`;
- `x0 = 0`;
- для каждого теста правая часть пересчитывается как `b = A*x_star`;
- `A = Q*D*Q^T`;
- для второго эксперимента после записи текущего результата максимальный диагональный элемент `D` делится на 10. На следующем шаге максимум определяется заново;
- в первом эксперименте порядок параметров фиксирован: `0-1-2`;
- в третьем эксперименте используется исходная система с `det(D)=1` и все шесть перестановок.

## Столбцы CSV

- `n`, `seed`, `max_cycles` — настройки вычислительного эксперимента;
- `eps`, `det_D`, `delta`, `Delta` — основные входные параметры и спектральные границы;
- `alpha0..alpha2`, `M3` — вычисленные параметры метода;
- `order` — порядок индексов параметров, например `2-0-1`;
- `cycles`, `iterations` — число полных циклов и отдельных шагов;
- `stopping_condition_met` — выполнено ли апостериорное условие остановки;
- `actual_accuracy_met` — достигнута ли фактическая ошибка `||x-x_star||_2 <= eps` (этот столбец возможен только потому, что в тестовом эксперименте точное решение известно);
- `error_estimate` — апостериорная оценка ошибки;
- `actual_error` — фактическая ошибка;
- `residual_norm` — норма невязки `||b-A*x||_2`;
- `first_cycle_error_step1..3` — фактическая ошибка после первого, второго и третьего шага первого цикла. Эти значения помогают увидеть влияние порядка параметров.

## Важные замечания

1. Условие остановки проверяется только после полного цикла из трёх шагов.
2. `stopping_condition_met` и `actual_accuracy_met` — разные показатели. При очень малых `eps` округление double может привести к тому, что оценка по разности соседних циклов станет нулевой или очень малой, хотя фактическая ошибка ещё больше `eps`. Для анализа точности нужно смотреть на оба столбца.
3. `MAX_CYCLES` установлен равным 100000. Если он исчерпан, `stopping_condition_met=0`; фактическая ошибка и невязка всё равно записываются.
4. `det_D` вычисляется как произведение диагональных элементов `D`. Для положительно определённой матрицы `A=QDQ^T` это также `det(A)`.
5. `alpha0..alpha2` вычисляются по формуле `2/(delta+Delta+(Delta-delta)*cos(...))`.
